Deadline feasibility check

Before you allocate: for each course date below, this adds up every unallocated, checked candidate whose programme deadline falls on or before that date (so they'd need to have started Stage 1 by then), and compares that against the total room capacity available across all courses up to that point. A shortfall means there are more deadline-bound candidates than Stage 1 can physically seat in time — worth knowing before you hit "Allocate now" in Step 3, not after. Pharmacy candidates with a placement-date clash on file aren't included (their eligible courses vary clash by clash, so they don't fit this simple running total) — check those individually.
