This year's assessment evenings

The Stage 1 evening courses running this year, in the order they happen. Name is exactly what will appear as the candidate's "course" — keep it consistent with what you've used before (e.g. "Course 1") so old and new records line up. Date is when that course's assessment evening falls, used to auto-fit candidates against the deadlines above. Capacity is per room, not a total headcount for the session — auto-fit multiplies it by the number of Stage 1 teaching rooms to get the real cap (e.g. 12/room × 18 rooms = 216 for that session). This is now applied automatically, by default, without needing to type anything here: the earliest-dated course gets filled first, up to 12/room, then everyone else spreads as evenly as possible across the remaining courses, up to 10/room each. Leave capacity blank on a row to use that default — type a number only if a specific course needs a different cap (fewer rooms available that date, say). Once every eligible course is full, auto-fit asks for permission before placing anyone over cap rather than just flagging them.
