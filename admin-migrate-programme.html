Writes every session in js/programme-data.js to Firestore as sessions documents (doc ID = session id, e.g. sat-9). timetable.html reads from this collection once it has data, and falls back to the static file until then — so running this is what switches the live site over to database-backed session times.

9 sessions are linked in pairs via a pairWith field — these are sessions that appear once in the data but show on both the instructor and assessor-stream tabs because they're the same real event (Saturday morning through the 11:45 break, plus the 16:45 Whole Course Photo). Linked pairs are marked below.
⚠️ Safe to re-run — it overwrites by session id, it won't create duplicates. But if the shift tool has already been used to move any session times live, re-running this will overwrite those live changes back to whatever's currently in js/programme-data.js. Only re-run intentionally, e.g. after editing the source file to fix a TBC location.
