Instructor Weekend: Data Export
RMD Birmingham · Director only · business continuity backup
← Course Director
Downloads a copy of the weekend's live records to this device, so the results survive if the site, Wi-Fi or Firebase has a problem. The files contain personal data and faculty comments about named candidates: keep them on your encrypted device or the University SharePoint, not on shared drives or email. Take a copy at the end of each day: Friday evening, Saturday evening, Sunday afternoon.
What to export

Each row also has its own CSV button, which opens in Excel for a quick look or for keying results back in. The JSON file keeps full detail (nested ratings, timestamps as ISO dates) and can be restored later if ever needed.

Pre-weekend test data check

Read-only. Looks for fake or left-over test people (names such as "test", "demo", "dummy", test email addresses, "IW Test" accounts) and for ratings that point at nobody, so they do not appear in the gateway sign-off table, pass confirmation, course report or paper sheets. It changes nothing. Anything it finds can be removed with the test data cleanup tool, which shows a preview first.
