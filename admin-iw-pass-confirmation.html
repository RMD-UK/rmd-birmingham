Instructor Weekend — Pass Confirmation
RMD Birmingham · Director only
This is the confirmation step Instructor Candidates need at the end of the weekend before they count as an Instructor permanently — until this runs, "not yet confirmed" is the correct, honest state for everyone on this list. Everyone defaults to Pass below, since that's the expected outcome — flip anyone who didn't pass to Fail. Before anything is saved you'll be asked to explicitly confirm the list of people being marked as not having passed, since that's the exceptional, higher-stakes action here. Saving records a permanent-standing period against each Pass candidate's own record (the same role-history mechanism Role History uses) — it doesn't touch this year's Instructor Weekend job assignment.

Longer term, Jon's plan is to fold this into the annual MoU Bulk Upload rather than run it as a separate page — this exists now so the confirmation step is real and usable for Instructor Weekend 2026 before that's built.
Confirmation date

Recorded as the start date of each Pass candidate's Instructor standing. Defaults to this year's Instructor Weekend end date — change it if you're running this on a different day.
